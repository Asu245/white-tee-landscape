# White Tee Landscape

A research hub for mapping the plain white T-shirt market and documenting the brands, products, positioning, pricing, and customer experience around it.

**Live research hub:** [https://asu245.github.io/white-tee-landscape/](https://asu245.github.io/white-tee-landscape/)

## Run locally

```sh
npm install
npm run docs:dev
```

Build the site with `npm run docs:build`.

## Research principles

- Keep observed facts separate from interpretation.
- Record a source and the date checked for every time-sensitive claim.
- Treat the initial brand watchlist as leads to validate, not a final competitor set.
- Use the profile template in `docs/competitors/_template.md` for each brand.

## Scope

This project currently studies the market. It does not represent a launched brand or commit to a product, supplier, or positioning direction.
